# 租房信息与费用确认表

一套房填写一份，由中介提供报价和合同信息，租客补充实际看房与交接记录。

**[下载 Excel 空白模板](outputs/01a11ae7-a608-7692-9440-5edb4b06cfa9/租房信息与费用确认表.xlsx)**

在 GitHub 文件页面点击下载按钮，再用 Excel 打开。模板无需宏，也不需要运行程序。

## 怎么使用

1. 每次看房先另存一份，建议命名为 `日期-小区-房号.xlsx`。
2. 请中介填写黄色单元格。蓝灰色单元格包含公式，请保留。
3. 金额只填数字，不附带“元”。没有该项收费填 `0`，尚未确认留空；计算结果会显示“待填写”，不会自动当作免费。
4. 文字项目不知道时写“待确认”，不适用写“不适用”。金额、责任和退租承诺应与合同对应。
5. 入住与退租分别留存交接记录，并保留读表、损坏和设备状况照片。

| 工作表 | 内容 | 填写时间 |
| --- | --- | --- |
| 费用报价 | 房租、押几付几、中介费、物业、水电燃气、宽带、停车、供暖、其他收费、首月预算 | 看房报价时 |
| 房源与合同 | 出租授权、收款主体、通勤、房屋状况、退押金、违约、续租、维修和额外收费 | 签约前 |
| 验房交接 | 家具家电、门窗、原有损坏、表底读数、钥匙、欠费、整改期限 | 入住和退租时 |

## 除了房租，还应该考虑什么

- **整体开销**：每月固定费、按用量计费、一次性收费、押金和预充值，分别是多少。
- **付款压力**：押一付三意味着首次通常要准备三个月租金和押金，另加本次其他收费。
- **水电口径**：民用还是商用、单价、独立表还是分摊、阶梯或峰谷价格、公摊和损耗怎么算。
- **退租成本**：押金多久退、能扣哪些项目、提前退租违约金、退租保洁和充值余额处理。
- **合同与责任**：谁有权出租、谁签合同和收款、维修由谁负责、涨租与续租规则。
- **实际居住体验**：通勤、噪音、采光、通风、潮湿发霉、异味、室友、网络、水压和热水。
- **交房状态**：家具家电是否能用、原有损坏、交付前欠费、钥匙数量、整改承诺是否有期限。

这些项目均在模板中留有填写位置。各地收费和具体条件由中介填写，模板不预设当地费率。

## 自动计算的口径

| 结果 | 计算方法 |
| --- | --- |
| 首期租金 | 月租金 × 付几个月；填写“首期租金约定额”时优先使用约定额 |
| 房屋押金 | 月租金 × 押几个月；填写“房屋押金约定额”时优先使用约定额 |
| 每月固定支出 | 月租金 + 各项固定费用月均金额 |
| 每月预计支出 | 每月固定支出 + 水、电、燃气的单价 × 预计月用量 |
| 首期固定费用预收 | 各项月均金额 × 各自首期预收月数，再求和 |
| 签约 / 入住应付总额 | 首期租金 + 首期固定费用预收 + 一次性费用 + 押金合计 + 预充值 |
| 签约 / 入住尚需支付 | 签约 / 入住应付总额 − 已付且可抵扣款项 |
| 首月总共需付（含已付） | 签约 / 入住应付总额 + 首月入住后另外需付 |
| 首月还需准备 | 签约 / 入住尚需支付 + 首月入住后另外需付 |

首月总额是现金支出口径，包含押金及以后月份的预付租金；每月预计支出用来比较日常居住成本，两者不能直接相加。

### 容易填错的地方

- **押一付三**：押几个月填 `1`，付几个月填 `3`。
- **年付宽带**：年费 600 元，月均金额填 `50`；首次交全年，首期预收月数填 `12`。物业费等可使用不同的预收月数。
- **供暖费**：按全年费用除以 12 折算月均金额；短租、跨供暖季等特殊收费按约定换算预收月数，并在合同页写明覆盖期间。
- **包水电或没有燃气**：对应单价、月用量均填 `0`，说明栏注明“包含在租金中”或“不适用”。水电单价单位分别是元/吨、元/度，燃气是元/立方米。
- **阶梯或峰谷价**：填预计平均单价，并写明估算依据；每月金额是估算，实际按账单结算。
- **特殊首期租金或押金**：不足整月、免租、固定押金等，填写约定额。留空采用常规计算，填 `0` 表示该项实际免收。
- **首月入住后另外需付（第 41 行）**：填写首月内尚未被首付款覆盖的账单、搬家等金额。已预交的租金、物业费和水电充值不要重复填写。模板不会把整月水电估算再次加进首月总额。
- **已付款抵扣**：只填写确认可抵扣本次应付款的金额。超过本次应付款时会提示核对。
- **出现“待填写”**：到下方明细查找空白或异常项；填写数字后，Excel 会重新计算。
