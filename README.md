# 租房信息模板

一套房填写一份，发给中介确认房源地点、租房费用和联系人信息。

**[下载 Excel 空白模板](outputs/01a11ae7-a608-7692-9440-5edb4b06cfa9/租房信息模板.xlsx)**

在 GitHub 文件页面点击下载按钮，再用 Excel 打开。模板只有一张工作表，左列为项目，右侧“数值”列由中介填写。

## 填写内容

| 项目 | 填写说明 |
| --- | --- |
| 小区/地点 | 填写小区名称或房源所在地，便于区分不同房源 |
| 房租多少钱一个月 | 填写每月房租金额 |
| 押几付几 | 例如“押一付三” |
| 中介费多少 | 填写租客实际承担的中介费 |
| 水费电费多少 | 分别写清水费、电费单价及单位 |
| 物业费多少 | 填写金额与收费周期；包含在租金中时注明 |
| 燃气费 | 填写单价及单位；不适用时注明 |
| 首月总共要付多少 | 请中介核算首期租金、押金、中介费及其他首月应付款，并确认是否包含已付款 |
| 中介姓名 | 填写该房源的对接中介姓名 |

## 怎么使用

1. 每次看房另存一份，建议命名为 `日期-小区-房号.xlsx`。
2. 请中介在右侧“数值”列填写对应信息。没有收费填 `0`，未确定的项目写“待确认”。
3. 这是一份手动填写表，不含自动计算公式。首月总额需要中介核算并填写。
4. 签约前将各项费用与合同核对，特别确认押几付几、水电收费标准和额外收费。

## 可直接发给中介的话

> 麻烦填写这份房源信息表，先写明小区或地点，再写清月租、押几付几、中介费、水电、物业和燃气收费，以及首月总共要付多少。没有的收费填 0，没确认的写“待确认”，最后留下对接中介姓名，谢谢。

## 文件保存

公开仓库保存空白模板和说明。填写后的记录请保存在项目外，或放入已被 Git 忽略的 `填写记录/`、`private/` 目录。
